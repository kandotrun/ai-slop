# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that includes exploit details, credentials, user data, or a live private preview URL.

Use GitHub's private vulnerability reporting from the repository's **Security** tab. If that option is unavailable, use the [ギガサイト便 contact form](https://giga-site.com/contact?type=question) and select the general inquiry category. Include:

- affected route or component
- impact and prerequisites
- minimal reproduction steps
- whether the issue has been tested against production

Do not include real credentials or third-party personal data. We will acknowledge actionable reports and coordinate disclosure after a fix is available.

## Supported version

Security fixes are applied to the default branch and the currently deployed production version.
